# ResilienceGuard Build Plan

## Objective
Deliver a runnable local recovery-readiness MVP, evidence-backed reports, and polished Eureka submission documents. All source data is synthetic. Recovery actions are limited to explicitly approved sandbox restores.

## Phases
1. [x] Inspect workspace and establish operating instructions and project plan.
2. [x] Verify standards, competitor landscape, dependency versions, licensing, and deployment choices using primary sources.
3. [x] Create reproducible synthetic inventory, backup files, manifests, scenarios, and architecture diagram.
4. [x] Produce the idea document, pitch deck, business case, and technical design.
5. [x] Implement FastAPI recovery assessment API, deterministic graph engine, persistence, report export, and synthetic loader.
6. [x] Implement React/TypeScript dashboard, governed assistant, and human approval flow.
7. [x] Implement isolated restoration and validate measured outcomes.
8. [x] Run automated evaluation and security dependency checks; compare AI fallback and rule-only plans.
9. [x] Update documents with verified implementation results.
10. [x] Export and inspect final DOCX/PDF/PPTX artifacts and verify local run instructions.

## Delivery rules
- Use safe defaults and no production connectors.
- Prefer a small, runnable local stack over services that require external accounts or large model downloads.
- Keep dependency pins and licensing rationale documented.
- Record completion and evidence in PROGRESS.md after each phase.
